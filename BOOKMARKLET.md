# Resume Assistant Bookmarklet

Use this when you want the dashboard without Tampermonkey.

## Setup
1. Open `smart-resume-assistant-bookmarklet.url.txt`.
2. Copy the full `javascript:...` line.
3. Create a browser bookmark and paste that line as the URL.
4. Open any job application page and click the bookmark.

## Features
- Floating **Box mode** for inline copy/fill.
- **Tab mode** for wider browsing/filtering view.
- Full resume information preserved for job applications.
- Fast category filter + keyboard navigation.

## Shortcuts
- `Alt+X` → show/hide box
- `Alt+Q` → focus filter box instantly
- `Alt+T` → open Tab mode
- `↑/↓` → select row
- `Enter` → copy selected value
- `Shift+Enter` → fill currently focused input

## Source
If you want to edit behavior/data, update `smart-resume-assistant-bookmarklet.js` and regenerate URL text file.
